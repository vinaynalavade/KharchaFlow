Privacy & Data Architecture

Privacy Policy

Last updated: September 2026

1. Core Privacy Philosophy

KharchaFlow is designed with strict on-device data privacy as a fundamental principle. We believe personal financial data belongs solely to the user and should never be transmitted to third-party marketing servers, data brokers, or analytics networks.

2. Data Storage & Local Persistence

All financial records, transaction entries, amounts, custom category labels, income/expense sources, and user configuration preferences are stored exclusively on your Android device in a private local database.

  • Zero Remote Accounts: You do not need to register, create a username, or provide an email address to use KharchaFlow.
  • Zero Telemetry: KharchaFlow does not embed any tracking or analytics libraries.
  • Zero Advertising: KharchaFlow contains no advertising SDKs, promotional banners, or tracking identifiers.

3. Application Permissions & Usage

KharchaFlow requests only the minimum necessary system permissions required to deliver requested on-device features:

  • Notifications: Used solely to deliver user-enabled daily expense reminder notifications and scheduled EMI due alerts.
  • Device Startup: Used strictly to re-register your local daily reminders after your device is restarted.
  • App Updates: Used only when you manually check for and confirm an in-app APK update from Settings.
  • Internet Access: Used solely for downloading user-initiated in-app updates from GitHub and for optional user-initiated Google Drive backups.

4. Optional Google Drive Cloud Backup

KharchaFlow supports an optional cloud backup feature. If you choose to enable it:

  • Direct Connection: Backup operations connect directly between your device and Google's official authorization servers with zero intermediary KharchaFlow servers.
  • Private App Folder: Backup files are stored inside your private Google Drive app folder where only your personal installation of KharchaFlow can access them.
  • Complete User Ownership: KharchaFlow has no remote servers and cannot access your Google Drive or view your stored files.
  • Guarded Restores: Restoring data requires explicit user confirmation to prevent unintended local overwrites.

5. On-Device Security & App Lock

KharchaFlow provides optional local security features to protect your privacy on your device:

  • Biometric Unlock: Supports fingerprint and facial recognition via Android system authentication.
  • PIN Lock: Secured on-device with cryptographic hashing.
  • Window Privacy Protection: When enabled, KharchaFlow masks application screen contents in Android's recent applications switcher.

6. Open Source Transparency

The entire source code of KharchaFlow is publicly available for verification and audit on GitHub at https://github.com/vinaynalavade/KharchaFlow.
