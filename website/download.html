How To Install

Step-by-step Android installation guide

Because KharchaFlow is distributed outside Google Play, Android requires a one-time permission to install APKs.

  1. 1

    Download APK

    Tap the Download Official APK button above to save the latest release file onto your Android device.

  2. 2

    Open the File

    Once downloaded, tap the notification in your notification bar or open the APK from your browser's Downloads menu.

  3. 3

    Allow Source

    If Android displays "Install unknown apps", tap Settings and toggle on Allow from this source.

  4. 4

    Complete Install

    Return to the installer dialog and tap Install. KharchaFlow is now ready to use offline.

Future Updates

Built-in APK update checker

You do not need to manually check this website for updates in the future. KharchaFlow includes an integrated in-app update checker located in Settings → App Updates.

When a new version is released on GitHub, the app can discover the update, stream the download with progress indicators, verify the SHA-256 checksum and package archive, and hand off installation to Android seamlessly.

In-App Updates Workflow

  • Automated release detection from official GitHub API
  • SHA-256 integrity verification before prompting install
  • Downgrade rejection and package identity checks
System Requirements

Compatibility & Specs

Android OS

Requires Android 8.0 (API level 26 — Oreo) or higher. Fully compatible with Android 9 through Android 15.

Storage

Lightweight footprint. APK download is under 4 MB, requiring under 15 MB of on-device space after installation.

Google Services

Google Play Services is not required for core offline tracking. Google services are used only if you choose to enable optional Google Drive backups.
